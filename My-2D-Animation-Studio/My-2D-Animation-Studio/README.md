# My 2D Animation Studio

A beginner-friendly browser-based 2D animation starter project.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Customize the character, scene, background, and motion.
4. Press **Play** to preview.
5. Use **Export video** to record a 5-second WEBM preview (browser support required).

## Included
- Character colour and expression controls
- Background and ground colour controls
- Gentle bounce, wave, walk-in-place, and idle motions
- Scene title and character name
- PNG preview export
- Short WEBM video export

## Notes
This is a starter studio, not a full professional frame-by-frame animation editor. It runs locally and does not need a paid API or server. Advanced features can be added in later versions.
